# RL AIWe build open-source AI applications: autonomous agents that do realwork, run on your own hardware, and stay under your control.Our first product is in pilot today — and the pilot is open. Feedbackfrom people running it shapes the roadmap.## Aerial — pilot release (beta)**Aerial is the control tower for a swarm of autonomous agents.**Agents fly solo — finding opportunities, running 24/7, self-healingwhen infrastructure fails — while the operations layer keeps the wholeswarm coordinated, evidenced, and saturated.- **Ticket hub** — tasks as shared context: multiple agents and roles  work the same task, each inheriting the chain of evidence and  decisions- **Ops agent** — polls every 5 minutes: failures classified, ticketed,  fixed, and re-verified. The fix isn't done until a symptom probe proves it.- **Fleet manager** — bring your own model (local VRAM, self-hosted, or  cloud); VRAM management, seat-swap, self-healing seats- **Built-in reporting** — daily board, exec report, usage per call and  per seat on a 15-minute cadence- **Fully local** — hub, console, runners, and models on your hardware.  No telemetry. No data leaves the machine.Pilot release (beta): the core is production-tested daily on the team'sown fleet, but not yet packaged for general distribution.→ [github.com/rl-ai/aerial](https://github.com/rl-ai/aerial) ·[Getting started](https://github.com/rl-ai/aerial/blob/main/GETTING-STARTED.md) ·[60-second teaser](https://rl-ai.github.io/aerial-teaser.html)## ContributeThis is a pilot — feedback is the roadmap.- **Running it?** Post your setup in  [Discussions → Show and tell](https://github.com/rl-ai/aerial/discussions) —  model seats, workflows, integrations, screenshots- **Found something broken?** [Bug report](https://github.com/rl-ai/aerial/issues/new?template=bug.md) —  include `bin/aerial_verify.py` output; it's the most useful thing you can send- **Want something?** [Feature proposal](https://github.com/rl-ai/aerial/issues/new?template=feature.md)- **Code contributions welcome** — see [CONTRIBUTING.md](https://github.com/rl-ai/aerial/blob/main/CONTRIBUTING.md)Known limitations and the running fix log:[ROADMAP.md](https://github.com/rl-ai/aerial/blob/main/ROADMAP.md) ·[docs/BUGLIST.md](https://github.com/rl-ai/aerial/blob/main/docs/BUGLIST.md)## Where we came fromRL AI started as AI-assisted investing research: market-data pipelines,feature engineering, backtesting, and model evaluation for systematicstrategies.
